# Обложка мероприятия Ticketland: блок по высоте картинки

Статическая копия страницы мероприятия [«Концерт French Montana»](https://www.ticketland.ru/kluby/klub-vk-stadium/french-montana/), в которой цветной блок с афишей занимает ровно высоту самой картинки. Размытие остаётся слева и справа от неё.

**Открыть страницу:** https://konoplitski.github.io/cover-block-demo/

| Экран | Было | Стало | Картинка |
|---|---|---|---|
| 1920×1080 | 648px | 270px | 420×270 |
| 1536×864 | 518px | 270px | 420×270 |
| 1280×720 | 432px | 270px | 420×270 |
| 1024×768 | 461px | 244px | 364×234 |
| 768×1024 | 614px | 240px | 258×166 |

На узких экранах (1024px и 768px в таблице) текст выше ужавшейся картинки, поэтому блок идёт по тексту. Мобильная раскладка не менялась.

## Что изменено

Вся правка — `cover-block.css`:

- высота блока больше не зависит от высоты окна (было `60vh`), а берётся от картинки;
- картинка показывается в натуральном размере и прижата к правому краю контентной области, её область начинается после текстовых колонок;
- размытие остаётся в правой части блока, фон под текстом не меняется.

## Структура

- `index.html` — страница
- `cover-block.css` — новая раскладка блока
- `local-fixes.css` — логотип для открытия с диска: Chrome не применяет CSS-маску к файлу, открытому через `file://`
- `site/` — стили, шрифты и картинки сайта без изменений (переписаны только пути к файлам)
- `preview/` — снимки «было / стало»

На странице есть переключатель «Новая раскладка блока» в правом нижнем углу: он показывает исходный вид.

Это статическая копия: без скриптов сайта не работают кнопки, поиск и стрелки каруселей, секция с картой исключена.
